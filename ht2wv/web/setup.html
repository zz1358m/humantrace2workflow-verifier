允许 ht2wv 读取哪些记录？

ht2wv 从你已有的电脑使用记录里提炼工作流程和你的验收标准。下面每一项都要你明确勾选才会读取；没勾的不会碰。数据只存在本机 。

1连接你的服务器

先把常用的服务器加进来并测试连通。只使用密钥登录，不会询问或保存密码。

2本机上的记录

灰色的项目前不可用，按提示补全后会变为可选。

3需要你提供路径的来源

微信聊天记录
微信本地数据库是加密的，ht2wv 不会去解密。请用你信任的导出工具导出为 csv / jsonl / txt，再填路径。
工作目录
只读这些目录下文档类文件的文件名与修改时间，不读内容。

4交给 coding agent 分析

开始分析后，上面勾选的记录（脱敏后）会被你选的 coding agent 读取，也就是发送给对应的模型服务商。选“只生成任务书”可以先看会发什么。
